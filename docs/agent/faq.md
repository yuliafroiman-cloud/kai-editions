# KAI Assistant — שאלות נפוצות

> התשובות מבוססות מילה-במילה על [../website-copy.md](../website-copy.md) §8. הסוכן יכול לקצר ולנסח בטון שיחה, אבל לא לסתור.
> בסוגריים — וריאציות ניסוח של אותה שאלה, כדי שהסוכן יזהה אותן.

## אפשר לראות את העיצוב לפני ההזמנה?
(איך אני יודע איך זה ייראה / יש דוגמה / רואים את הקלפים קודם?)
אפשר לראות את **הקונספט** אחרי שמעלים כמה תמונות ראשונות ועונים על כמה שאלות קצרות. כדי לשמור על אפקט ההפתעה, לא רואים מראש את העיצוב המלא של כל הקלפים — את הקולקציה השלמה מגלים כשהקופסה מגיעה.

## כמה זמן לוקח עד שהקופסה מגיעה?
(מתי זה מגיע / זמן משלוח / זמן אספקה / כמה זמן ייצור)
כל קופסת KAI מיוצרת במיוחד עבורכם. זמן הייצור והמשלוח הוא **עד 21 ימי עסקים** — אנחנו משקיעים את הזמן כדי שכל פרט יהיה מדויק ואישי. כי יש הפתעות ששווה לחכות להן.

## התמונות עוברות עריכה ב-AI?
(משנים את התמונות / מעבדים / פוטושופ / בינה מלאכותית על התמונות)
לא. התמונות נשארות בדיוק כפי שהעליתם אותן. אנחנו לא משנים אנשים, הבעות או רגעים — רק עוטפים אותן בעיצוב ובחוויה.

## כמה תמונות צריך להעלות?
(כמה תמונות / מינימום תמונות / כמה צריך)
תלוי בחבילה. מתחילים עם כמה תמונות כדי לקבל את הקונספט הראשוני, ואז משלימים את השאר לפי כמות הקלפים בחבילה. המערכת מנחה אתכם בתהליך.

## כמה זמן לוקח למלא את ההזמנה?
(התהליך ארוך / כמה זמן ההעלאה / מסובך?)
ממש לא. תוך כמה דקות בוחרים קולקציה, מעלים תמונות, עונים על כמה שאלות קצרות ומתחילים. המערכת גם יכולה לעזור בניסוח הברכה.

## מה מבדיל את KAI מאלבום תמונות רגיל?
(למה זה שונה / מה מיוחד / זה סתם אלבום?)
אלבום רגיל מציג תמונות. KAI הופכת אותן לחוויית גילוי: קלפים בחפיסות סגורות ובסדר אקראי, קלפי Silver ו-Gold, ברכה אישית, אלבום, ואלמנטים של הפתעה ואיסוף. והכי חשוב — פותחים יחד ומגלים כל זיכרון מחדש.

## אפשר לשלוח את KAI ישירות כמתנה?
(משלוח למקבל המתנה / לשלוח למישהו אחר / כתובת אחרת)
כן. אפשר לשלוח את הקופסה ישירות לכתובת של מי שמקבל את המתנה, להוסיף ברכה אישית, ולתת להם לבחור מתי לפתוח.

## אפשר להזמין חפיסות נוספות בעתיד?
(להוסיף קלפים / להרחיב / קופסה שנייה)
כן. אפשר להזמין חפיסות נוספות ולהמשיך להוסיף זיכרונות. האלבום מגיע עם מקום להרחבת הקולקציה, כך שהיא גדלה יחד עם הסיפור שלכם.

## מה קורה לתמונות שאני מעלה?
(פרטיות / איפה נשמרות התמונות / מוחקים?)
התמונות משמשות אך ורק ליצירת הקולקציה שלכם. אחרי שהקופסה מיוצרת ונשלחת, התמונות נמחקות ממאגר המידע שלנו ואינן נשמרות.

## מה הופך את KAI למתנה מיוחדת?
(למה מתנה טובה / זו סתם עוד מתנה?)
KAI היא לא עוד מתנה חד-פעמית. זו חוויה שנבנית חפיסה אחר חפיסה — פותחים יחד, מגלים זיכרונות מחדש ומבלים זמן עם מי שיקר לכם.
