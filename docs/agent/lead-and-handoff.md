# KAI Assistant — איסוף ליד והעברה לצוות

> שלב 1: הסוכן אוסף שם + דרך קשר, שומר ל-Google Sheet, ושולח מייל התראה ליוליה + מייל תודה ללקוח (אם נמסר מייל).
> שלב 2 (בהמשך): חיבור וואטסאפ.

## מתי לאסוף ליד
לאחר שהתקיים **אחד** מאלה, ורק אחרי שהגולש מסר **שם** ולפחות **טלפון או מייל** בפועל בשיחה:
- הגולש אמר שהוא רוצה להזמין / להתחיל / "איך מזמינים".
- הגולש ביקש שיחזרו אליו / לדבר עם אדם.
- שאלה שאין עליה תשובה מוכנה (מדיניות, התאמה מיוחדת, משלוח חריג).
- הגולש השאיר פרטים מיוזמתו.

לא ללחוץ. אם הגולש רק מתעניין — לענות, ובסוף להציע: "אם תרצו, אשאיר לצוות את הפרטים שלכם שיחזרו אליכם עם ליווי אישי."

## איך מבקשים (נוסח לסוכן)
> "אשמח שנלווה אתכם. איך קוראים לכם, ומה טלפון או מייל שנוח לכם שנחזור אליו?"

כשיש שם + דרך קשר → לקרוא **פעם אחת בלבד לכל שיחה** לכלי `Save Lead`, ואז:
> "מעולה, {שם} — רשמתי, והצוות של KAI יחזור אליכם. בינתיים אפשר גם להתחיל את ההזמנה כאן באתר."

## שדות הכלי `Save Lead` (מ-$fromAI)
| שדה | תיאור ל-AI |
|---|---|
| `full_name` | שם הגולש כפי שנמסר בשיחה |
| `phone` | טלפון ישראלי אם נמסר, אחרת מחרוזת ריקה |
| `email` | מייל אם נמסר, אחרת מחרוזת ריקה |
| `line` | קו שעניין את הגולש (Couple/Family/Friendship/Kids) אם עלה, אחרת ריק |
| `edition` | Edition אם עלה, אחרת ריק |
| `size` | גודל שנדון (24/48/72) אם עלה, אחרת ריק |
| `gift_for` | למי המתנה / למי הקולקציה, אם צוין |
| `summary` | סיכום קצר (משפט–שניים) של מה הגולש ביקש או שאל |

## מבנה ה-Google Sheet — "KAI EDITIONS — לידים מהצ'אט"
עמודות (שורת כותרת):

| שם מלא | טלפון | אימייל | קו | Edition | גודל | למי המתנה | סיכום שיחה | תאריך | מקור | sessionId |
|---|---|---|---|---|---|---|---|---|---|---|

- `תאריך` = `{{ $now.toFormat('yyyy-MM-dd HH:mm') }}`
- `מקור` = `צ'אט KAI (אתר)`
- `sessionId` = `{{ $('Webhook').item.json.body.sessionId }}` — לצורך איתור השיחה
