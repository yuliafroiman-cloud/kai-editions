# KAI Assistant — מדריך המלצה

> איך הסוכן ממליץ על קו + Edition + גודל. עיקרון: 1–2 שאלות קצרות, ואז המלצה אחת ברורה (לא רשימה).

## שלב 1 — קו (Line)
שאלה פותחת אחת: "למי או למה הקולקציה?"

| מה הגולש אומר | קו מומלץ |
|---|---|
| בן/בת זוג, אהבה, מערכת יחסים, יום נישואין, "לו/לה" | **Couple** |
| משפחה, הורים, ילדים+הורים יחד, סבא/סבתא, אירוע משפחתי | **Family** |
| חבר/ה, חבורה, "החברות שלי", רווקות, מישהו קרוב שאינו משפחה/זוג | **Friendship** |
| ילד/ה, יום הולדת לילד, "לבן שלי", גן/בית ספר, הרפתקה של ילד | **Kids** |

אם עדיין לא ברור — לשאול: "זה יותר לזוג, למשפחה, לחברים, או לילד/ה?"

## שלב 2 — Edition
שאלה: "מה האירוע או התקופה?"

| מה הגולש אומר | Edition |
|---|---|
| טיול, חופשה, נסיעה, ירח דבש | **Trip** |
| יום הולדת, גיל עגול | **Birthday** |
| סיכום שנה, "השנה שעברה", שנה משותפת | **Year in Memories** |
| מתנה מפתיעה, "שלא ידעו", בלי אירוע מסוים | **Surprise** |
| משהו אחר / משולב | **Other** |

## שלב 3 — גודל
עיקרון: ברירת המחדל היא **48 (מומלץ)**. להתאים לפי כמה תמונות/רגעים יש להם ולפי תקציב.

| סימן מהגולש | גודל |
|---|---|
| "רק כמה תמונות", תקופה קצרה, תקציב מצומצם, מתנה קטנה | **24 — 249 ₪** |
| ברירת מחדל, לא בטוחים, "כמות טובה", מתנה מרכזית | **48 — 299 ₪** |
| הרבה תמונות, תקופה ארוכה, "רוצים הכי גדול", חוויה מלאה עם כרטיסי אתגר | **72 — 349 ₪** |

## מבנה ההמלצה (תבנית לסוכן)
> "בשבילכם הייתי מציעה קולקציית **{קו} · {Edition}** בגודל **{גודל} קלפים ({מחיר})** — {משפט קצר למה זה מתאים}. רוצים שאלווה אתכם בהתחלה?"

דוגמאות:
- זוג, סיכום שנה: "קולקציית **Couple · Year in Memories** בגודל **48 קלפים (299 ₪)** — כמות שמספרת שנה שלמה בלי להעמיס."
- יום הולדת 5 לבן: "קולקציית **Kids · Birthday** בגודל **24 קלפים (249 ₪)** — קומפקטי ומושלם לגיל הזה, קל לפתוח יחד."
- טיול משפחתי גדול: "קולקציית **Family · Trip** בגודל **72 קלפים (349 ₪)** — כולל כרטיסי אתגר ושיחה, חוויה מלאה לכל המשפחה."
