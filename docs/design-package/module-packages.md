## ⚠️ שתי דרישות קשיחות (לא לפספס)

1. **בכל כרטיס חבילה חייבת להופיע הקופסה** — לא רק קלפים בודדים. ברור לעין שקונים **קופסת אספנות** (הקופסה הבורדו הסגורה או פתוחה עם התוכן), והקלפים/חפיסות הם מה שבתוכה.
2. **אסור להמציא מוצרים או עיצובים חדשים.** להשתמש אך ורק במוצר הקיים כפי שהוא מופיע בצילומי המסך:
   - קופסה בורדו עם לוגו KAI זהב (ראה `06-whatsinside`, `04-collections`).
   - חפיסות פויל בורדו עם "KAI EDITIONS" זהב (ראה `07-cardreveal`).
   - קלפים במסגרת בהירה/כסף, וקלף Gold זוהר (ראה `07-cardreveal`).
   - אלבום בורדו, כרטיס ברכה שמנת, סט מדבקות.
   אין ליצור: אריזות בצבע אחר, חפיסות בצורה/מרקם שונה, קלפים בפריסה אחרת, אייקונים חדשים, badges, "פיצ'רים" שלא ברשימה.

- שם החבילה = סריף דיו כהה. הכמות = ink-soft. המחיר = סריף גדול.
