## מה הסקשן הזה עושה

## מבנה מוצע (בהתאם לשפת KAI)

```
                — ✦ —
        זיכרונות שחוזרים לחיים          ← כותרת עברית סריף גדולה, דיו כהה
KAI הופכת תמונות שנשארות בגלריה          ← משפט אחד, ink-soft, ממורכז (מהנוסח המורחב)
    לחוויה שלא שוכחים.

┌───────────────┐  ┌───────────────┐  ┌───────────────┐
│      ✦        │  │      ✦        │  │      ✦        │   ← אייקון/כוכב זהב קטן
│  לשמור אמיתי  │  │ לאסוף את הסיפור│  │    לרגש       │   ← כותרת בולד סריף (בצבע קו/דיו)
│               │  │               │  │               │
│ התמונות       │  │ חוויה שנבנית   │  │ כל חפיסה      │   ← משפט מודגש
│ נשארות בדיוק  │  │ חפיסה אחר חפיסה│  │ מחזירה לרגע.  │
│ כמו שהן.      │  │               │  │               │
│               │  │ הסיפור שלכם   │  │ פותחים        │   ← משפט תומך, ink-soft
│ בלי עיבודי AI │  │ הופך לקולקציה │  │ ומתרגשים      │
│ ובלי לשנות    │  │ שאפשר לגלות,  │  │ מחדש.         │
│ את הרגע.      │  │ לסדר ולשמור.  │  │               │
└───────────────┘  └───────────────┘  └───────────────┘
```

- **3 עמודות**, מרווח נדיב, מפרידים אנכיים דקים בזהב-בהיר (כמו ב-Trust bar).
- כל עמודה: כוכב ✦ קטן זהב · כותרת בולד סריף · משפט מודגש · משפט תומך ink-soft.
- סדר RTL: "לשמור אמיתי" מימין, "לרגש" משמאל (כמו שקוראים).
- **וריאציה אפשרית:** הסקשן הזה יכול להיות **כהה ואימרסיבי** — רקע נייבי `#141A24`, טקסט שמנת, כוכבי זהב, אולי תמונת רקע עמומה של ידיים פותחות חפיסה. זה שובר את רצף השמנת באמצע העמוד. תבחרי לפי מה שנראה לך.
- מובייל: 3 עמודות → טור אחד, כל אחת עם קו-הפרדה מעל.

## טקסטים מדויקים (מ-website-copy.md §6 — לא לשנות)

**כותרת:** זיכרונות שחוזרים לחיים
**משפט פתיחה (אופציונלי, מהנוסח המורחב):** KAI הופכת את התמונות שנשארות בגלריה לחוויה שלא שוכחים.

| כותרת | משפט מודגש | משפט תומך |
|---|---|---|
| לרגש | כל חפיסה מחזירה לרגע. | פותחים ומתרגשים מחדש. |
| לאסוף את הסיפור | חוויה שנבנית חפיסה אחר חפיסה. | הסיפור שלכם הופך לקולקציה שאפשר לגלות, לסדר ולשמור. |
| לשמור אמיתי | התמונות נשארות בדיוק כמו שהן. | בלי עיבודי AI ובלי לשנות את הרגע. |
